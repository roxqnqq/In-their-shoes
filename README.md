# In-their-shoes
O aplicație imersivă în VR care îi oferă utilizatorului posibilitatea de a trăi direct interferențele perceptive din schizofrenie în timpul unei sarcini cotidiene în bucătărie, având ca scop măsurarea și reducerea stigmatizării sociale prin reflecție ghidată și un narativ educațional.
